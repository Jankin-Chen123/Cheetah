# 前端交互演示与后续接入

本轮交付 React / TypeScript / Ant Design 前端页面与本地状态交互，不代表真实业务闭环已完成。本页记录最初前端交付边界；后续 A 已实现的后端接口与验证见 [A 交付说明](backend-a-delivery.md)。前端业务页仍未接入，不能据后端新增接口宣称页面已联调。

## 启动与状态

在 `frontend/` 使用 Node.js 24，运行 `npm ci`、`npm run dev`，访问 `http://localhost:5173/`。生产构建运行 `npm run build`。本轮未部署、未提交或推送。

默认进入明确标记的演示工作区。全部姓名、企业、简历、电话与报告为虚构样例。岗位、规则、审核、材料摘要及下载请求仅保存在页面内存，不写入 localStorage / sessionStorage / IndexedDB；刷新清空。材料文本不会当作 HTML 或执行指令。

目前只有 `src/api/client.ts` 请求统一 `/api/v1/health`，保留超时、取消与响应校验。基础服务在线不代表数据库、登录、AI 或电话已就绪；登录入口明确显示待接入，不收集或存储密码，也不伪造成功会话。

报告修订仅修改 D10 的本地人工稿；保存新版本时失效旧 D10 及旧批准，上游模拟来源保留。不会重拨、模型重生成或自动交付。D08 等上游事实更正及依赖重算尚未实现，不用修改推荐文稿代替事实更正。历史候选人保留实际绑定的规则版本，不随岗位新版本变化。

## 接口接入边界

`src/domain/workspace.ts` 是本地演示模型，不是已冻结的公共 API 合同。后端实现前需要按开发计划冻结字段；不能将演示状态直接上传为真实业务结果。

详细的后续对接设计已补充到 [前后端接口文档](api/README.md)，包含 [OpenAPI 草案](api/openapi.v1.json)、数据模型、前端字段映射、虚构样例和验收清单。该文档是待三方评审的实现目标，不改变本页列出的实际实现范围。

后续接入建议依次替换：鉴权与岗位 → 草案与规则发布 → 批次与候选人 → 产物和证据 → 电话状态和取消 → 报告审核与服务端导出。所有请求保持在 `src/api/`，使用统一 `/api/v1`；业务数据不能在请求失败时自动降级为演示成功。

接入异步任务后，再增加约 3 秒活动任务轮询、离页和终态取消、服务端错误分类与请求标识、401 会话失效处理。当前没有真实活动任务，因此不虚构任务 ID、执行百分比或轮询端点。

## 验证

- `npm ci`：本地清洁安装成功，审计返回 0 个漏洞；本轮没有增删依赖或修改锁文件。
- `npm run check`：ESLint、TypeScript 与 Vite 构建；另运行 `npm test`。
- 12 个针对性测试覆盖报告版本审核、缺证据阻断、旧批准失效、D09/D10 导出隔离、上游模拟来源、停止等待确认、外部结果不明、规则版本快照与导入内容去重。
- 实际浏览器已验证：创建岗位、规则未发布时禁止导入、测试规则新版本发布、未批准禁止下载、批准后的 Markdown 下载、修订 v2 后须重审、停止请求等待模拟确认、文本与改名文件去重、格式错误与其他材料互不影响。390px 手机宽度下没有页面横向溢出，已查看桌面与手机截图。
- 上述结果只证明前端模拟流程，不证明后端、真实 AI、真实电话或业务质量。浏览器截图与临时下载仅放在被忽略的 `work/`。

Linux CI、Docker 和线上环境未在本轮执行。构建会提示 Ant Design 所在入口包超过 500 kB；后续可随页面拆分优化加载，当前不影响构建通过。
