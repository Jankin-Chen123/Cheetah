## 已修复问题

1. **旧版 DOC 不兼容。** 增加 Word 97—2003 OLE 与主文档片段表读取，限制流大小、校验偏移与字符范围、拒绝加密和损坏文件。上传入口同步接受 DOC，失败仍逐份返回。未安装服务器 Office，也不执行材料中的宏或链接。
2. **推理占满输出额度。** 实际响应曾以 length 结束，16000 个输出 token 全部用于推理、正文为空。DeepSeek 结构化提取默认关闭 thinking，允许显式覆盖；其他提供者不默认发送该扩展。读取超时默认 90 秒、任务租期默认 300 秒。
3. **已返回坏响应被误认为外部结果未知。** 正常返回后的截断或无效正文改为明确失败，结算一次模型用量。已知坏响应进入受保护缓存，允许的显式格式恢复只重放缓存；真正网络结果不明仍阻止自动重发。截断不自动重试。
4. **结构化输出兼容性。** 支持完整 JSON 代码围栏及正常结束响应的括号／分隔符恢复；键、标量与冒号序列必须全部保留，再校验完整合同和原文依据。不补造字符串、值或缺失章节。字段层级错置仅恢复已有的已知章节；未知与冲突值清空，保留表单说明。初筛建议中的无意义空 dimensions_note 可忽略，非空额外字段仍拒绝。
5. **页面误导与信息缺失。** 失败／等待核对不再统称“等待匹配”；档案显示实际失败原因，部分识别提示与限制可见；逐份导入错误区分 PDF、Word、编码与限额。

开发过程中部分真实响应已由服务端或本地诊断保存。修复后的复核使用这些原响应，不额外调用模型；诊断缓存关联同时核对唯一用量和执行时间，再通过同一材料的原文校验。最早一轮外部结果未知记录没有自动重发，也没有伪造为成功。本次结果来自修复后的独立验证账号，不混用早期失败批次。
