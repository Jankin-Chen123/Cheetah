# AI面试修复与验收记录

本记录核对用户本轮及此前提出的网页语音面试问题。外部调用使用本地凭据，测试候选人材料为虚构样例。检查时间为2026年11月14日。

## 功能与证据

| 用户要求 | 当前实现与核验 |
| --- | --- |
| 说话打断AI | 麦克风检测到发言即停止排程音频并取消本轮合成请求，保留开头音频。采集与交棒测试通过，真人回声环境待验收。 |
| 更自然的可选音色 | 火山Vivi、小何、团子、云舟、小天、刘飞六种2.0音色均实际合成成功，页面可选择试听。自然度需要实际听感判断。 |
| 自己接音色 | 已支持配置服务商生成的自定义音色ID和名称，火山复刻使用独立复刻资源。尚未收到样本或复刻音色ID，个人声音复刻尚未执行。 |
| 延长时长 | 体验场次单次回答10分钟、整场60分钟，另有30轮上限。静音交棒1.2秒，长停顿会提前交棒。 |
| 同一网页可重测 | 新一轮创建独立场次，保留旧记录，真实候选人HTTP接口已验证。邀请有效期仍适用。 |
| 没有、可以继续等短句 | 明确意愿通过程序处理，复杂表达交给模型理解。首轮拒绝和确认继续均通过实际火山转写链。 |
| 全程理解自然语言 | 正式轮次先调用豆包理解意图、上下文和记忆，支持反问、解释、更正、换题及结束。开场复杂表达使用模型并携带近期交流。 |
| 知识库辅助 | 理解后改写查询，词项与向量融合检索，过滤低相关材料；无匹配正常回复。提纲生成也允许知识库为空，有引用时仍检查真实性。 |
| 连续记忆 | 追问接收累积事实及本轮更正，原文和answer_id核验后保存，未知保留未知。回归测试覆盖记忆更正和累积上下文。 |
| 模型错误后可继续 | 失败保留回答与故障来源，返回程序续接话语；转写失败保留审计并允许新轮收音。预算和鉴权限制仍执行。 |
| 邮件与开场顺序 | 求职意愿、简短职责薪资介绍、处理授权邮件并提示状态、确认继续、正式提问。提前打断介绍的肯定不会越过此顺序。 |
| 个人QQ邮箱发件 | 本地SMTP已配置，既有测试由SMTP接收。收件支持常见邮箱；服务器接收与最终送达分别显示。当前五段语音回归未额外发送邮件。 |
| 双轨字幕 | AI与候选人独立保留。AI文字在首段音频播放开始时整段显示，当前没有逐字时间对齐。 |
| 拒绝和结束有问候 | 均提供简短告别。修复结束后报告版本变化导致告别语音409的问题，实际结束语音合成通过。 |
| AI主动结束 | 候选人明确结束、场次时间或轮数上限、模型根据提纲覆盖给出end。模型完成判断仍可能波动，缺少证据不会等同达标。 |
| 全面切换火山模型 | 本地文本与向量使用方舟，实时与录音转写、普通合成及结束合成跟随火山语音配置。缺凭据或服务失败会保留真实失败状态。 |
| 降低等待 | 流式转写、流式播放、交棒固定等待减少600毫秒；岗位反问与无知识命中轮次省去第二次生成。服务端阶段耗时保留以定位长尾。 |

## 已执行检查

- 24项真实文本表达矩阵通过预设检查，覆盖意愿、姓名、反问、换题、更正、未知、工具经验和结束请求。此检查只代表所测样本。
- 8轮真实连续文本对话完成，含20位更正为12位、区分团队成果、换题和结束；未出现技术降级。部分回复仍冗长或转向不够自然。
- 五段火山合成音频经过网页代理、实时转写、候选人动作和模型worker闭环，确认继续后正常回答解释问题、程序停止并成功合成告别；首轮“没有”正常结束。
- 六种官方音色与网页试听接口实际合成成功。单次网页首音频约1.2秒，批量测试曾出现约11秒首音频等待。
- 后端测试、Ruff检查、合同Schema检查及前端静态检查、构建和16项前端测试通过。前端构建仍有包体积提示，摄像头组件有一条既有Hooks警告。

## 仍需核验的体验与外部能力

语音验证使用合成输入，真人麦克风、回声、连续打断和实际扬声器出声延迟尚未完成浏览器验收。部分文本轮次仍需十几秒，模型回复偶有重复、冗长和过早带回面试的问题，当前证据不足以判定已达到豆包客户端或真人面试的交流效果。

自定义声音复刻需要有效样本或已创建的音色ID及资源权限。当前实现为模型上下文和混合检索，尚未进行LoRA训练。

已阅读合同说明及开发计划D07—D10部分。当前代码包含结束后D08、D09及条件D10调度、具体版本审核和导出。真实电话线路适配、服务商真实回调核对及真实上游A事件的生产闭环仍需外部接入与联调。网页语音验证不能替代这些验收。
