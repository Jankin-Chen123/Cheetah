# AI 面试与面试后流程验收

本页记录当前集成状态。完整交付仍待同一隔离案例的模型和浏览器验收。面试范围从已发布并绑定到案例的标准开始；D01—D06 是输入，不扩展上游业务。

## 本地运行

使用 Python 3.12、Node.js 24 和 PostgreSQL，按 [README](../README.md) 安装并应用迁移。Cheetah 本地验收端口为前端 5174、后端 8001；后端允许来源须包含前端实际访问地址，前端代理通过 `CHEETA_DEV_API_TARGET` 指向后端。先核对现有服务和活跃任务，再决定是否加载新代码。登录入口为 `http://127.0.0.1:5174/goal`，本地密码从环境配置读取。

只对隔离虚构案例按实际 case_id 调度和运行 worker。先用 `uv run python scripts/run_interview_worker.py --help` 核对当前筛选参数；禁止启动无范围限制的 worker。队列超时或外部结果不明时先核对已保存状态。验收不真实外呼、不发邮件、不外发报告。
