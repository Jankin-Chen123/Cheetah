# 官网与账号交付

日期：2026-11-14。仅本地开发交付，未提交、推送或部署。

## 页面与行为

| 入口 | 实际行为 |
| --- | --- |
| `/` 或 `#home` | 官网：品牌、岗位流程示意、能力状态、常见问题和演示入口；不虚构客户、效果指标或真实通话 |
| `#register` | 称呼、账号、密码及确认密码；真实注册接口，201 后自动进入账号区 |
| `#login` | 真实账号密码登录；错误密码、网络错误、重复提交等待提示；无默认账号 |
| `#app/overview` 及其他 `#app/…` | 登录门禁，刷新恢复 `/auth/me`；显示当前用户；新账号空列表；退出携带 CSRF |
| `#demo/overview` 及其他 `#demo/…` | 无需登录，使用明确虚构数据；不提交后端生成任务，不自动迁移资料到账号 |

桌面侧栏和窄屏账号菜单都提供退出及返回官网入口。会话在聚焦、页面恢复可见和每 60 秒重新检查，到期或业务 401 后卸载账号区；登录后仅恢复受控的站内工作区路径。退出失败保留失败提示，不宣称成功。密码、CSRF 与会话响应不写入本机岗位数据库或浏览器永久存储。

## 注册接口

`POST /api/v1/auth/register`：`RegisterInput → 201 Session + HttpOnly Cookie`。沿用已有身份表、密码 scrypt、会话和对象权限，无新增依赖或数据库迁移。请求必须带允许的 Origin；无需预先有 Cookie、CSRF 或业务幂等 key。

- 账号：3–40 位 ASCII 字母、数字、`_.-`，首位为字母或数字，区分大小写，全库唯一。
- 称呼：1–100 字符，至少一个非空白字符；保存时去除首尾空白。
- 密码：12–128 字符，保留原样加密；确认密码只在前端验证，不发送。
- 机构 ID 由服务端生成，注册建立独立机构，不接受客户端传入的机构或权限；不提供团队邀请或加入已有组织。
- 重复账号返回 409 `USERNAME_TAKEN`，不更改当前会话；并发注册由数据库唯一约束保证只有一个账号。成功注册或登录轮换当前会话。
- `CHEETA_REGISTRATION_ENABLED` 默认 `true`；设为 `false` 时返回 403 `REGISTRATION_DISABLED`。
- `CHEETA_REGISTRATION_ATTEMPT_LIMIT` 默认 5：每个直接连接来源每 10 分钟最多 5 次格式合法的注册尝试，包括重复账号。记录独立事务提交，失败不会撤销限流；不信任请求自带转发地址，反向代理下共享来源额度。超限 429 `RATE_LIMITED`。
- 响应丢失时不自动重发注册，可先尝试使用同一账号登录。

运行时 OpenAPI、完整草案、样例、模型说明与前端生成类型已同步；本次不修改内部事件模型。

## 数据与范围

本机岗位库、搜索与列表视图按用户 ID 分开；演示继续使用原匿名演示库，保留此前材料。切换账号重新挂载工作区并读取对应存储。新账号不会载入虚构候选人或其他账号岗位；退出不会清除本机材料。同一浏览器的分库属于产品数据隔离，不能抵挡能操作同源浏览器存储的本机使用者；共用设备需自行清理资料。服务端继续执行对象权限。

本机列表不支持跨设备恢复，人工产物修订仍未回写后端。候选人、电话和推荐真实列表尚未接入；账号区暂时为空，演示区保留原交互。自动语音转写、团队管理、自助找回密码、邮箱验证和正式部署不在本次交付中。生成岗位产物仍需要实际模型和 worker 就绪，账号测试不代表模型业务已验收。
