# 腾讯会议可选接入调查（2026-11-14）

当前决定：不作为网页语音验收依赖，不配置账号、不购买、不自动创建会议。

官方来源：
- [会议 SDK](https://meeting.tencent.com/sdk.html)：确认存在面向 OA/CRM/ERP 集成的会议 SDK/API，但公开介绍页未给出原始音频读写或 AI 机器人入会接口合同。
- [使用 API](https://meeting.tencent.com/support-doc-detail/776/index.html)：页面说明企业/商业版 API、管理员密钥对及 APPID/SDKID；第三方应用通过 OAuth 用户授权。该页仍含“内测”历史文字，不能据此断定当前准入状态，实际开通须以账户控制台及最新申请审核为准。

尚未核实：本项目账户是否具备对应商业权限、SDK 支持平台与版本、原始音频订阅/回推授权、机器人入会和主持人许可、并发与计费、候选人录音同意、断线及停止行为。腾讯云 TRTC 文档属于另一产品，不能证明腾讯会议开放相同音频能力。

只有拿到对应官方接口合同与既有账户授权后才评估实现；目前不能承诺腾讯会议语音机器人可接入。网页受限链接、模型转写和 TTS 主路径继续独立开发。
