# A02 新材料接入差异

## 与现有实现的关系

A02制定岗位专属标准；A06面试、A07提取、A08评分的材料编号不能直接替换本工程D01—D10编号。当前D09/D10仍使用绑定案例的演示配置，不因新增材料自动成为正式专业评估。

新要求：动态且有岗位来源的能力维度；权重合计100%；各维度独立的1—2/3—4/5—6/7—8/9—10行为锚点；标准与权重须人工确认；没有证据未评估，覆盖率单列且不重新分配权重；折算=实际分÷10×权重百分数，未完成不出正式总分。

表单六列：考核维度、考核指标及解析说明、权重、评分标准（1—10分）、实际得分、折算得分。标准生成阶段后三项实际结果不预填；客户岗位信息六项保留未知；建议与客户确认事实分开，来源原话内部留存。

## 必须实施的兼容边界

现有0—5分演示配置与新1—10分标准不可静默混用，需显式评分量表/合同版本、对应验证和前端展示。旧案例继续绑定旧模板及哈希，禁止历史分数机械翻倍。新版岗位标准必须确认发布后绑定面试任务；更改权重或锚点产生新版本并使受影响下游失效。

不根据占位表凑维度，不自动批准方法，不将学历年限重复能力计分。新材料不是D10专业推荐模板。

## 当前接入增量

后处理已支持显式绑定已确认的 a02.v1 标准，按岗位、归属、revision 和递增版本校验，服务端记录确认人；接口及限制见 [本地接口说明](api/goal-local.md)。D09 支持显式十分制及整数评分，旧案例五分制快照保留原语义。更改绑定保存历史并使 D09/D10 失效，不重拨、不自动重算或交付。前端已提供标准确认表单和六列评估字段，百分制折算、权重覆盖及缺失不出总分有针对性测试。当前仍缺岗位标准自动生成、面试前自动绑定及浏览器验收；不能据此宣称 A02 全链路完成或已应用于旧报告。
