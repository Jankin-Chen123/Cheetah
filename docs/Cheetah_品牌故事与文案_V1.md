# Cheetah 猎报 · 品牌故事与文案 V1

> 英文名：Cheetah；中文名：猎报；品牌图形：猎豹。
> 主 slogan：**招对人，快人一步。**
>
> 本文确立命名与传播方向，描述产品愿景；功能是否可用以 README 和实际验收为准。

## 1. 品牌定位

**面向猎头的 AI 招聘工作台，让专业判断更快变成有据可循的推荐。**

服务对象是猎头顾问及其团队。围绕需求梳理、简历初筛、候选人沟通、评估与推荐，减少资料整理、反复核对和流程衔接中的等待，把猎头的时间留给深入沟通、专业判断与关系建立。

## 2. 名字里的三层含义

**Cheetah，是猎豹，也是行动的速度。** 猎头的工作存在时间窗口：需求会变，候选人的意向会变，合适的机会也会流动。猎豹代表敏捷和专注；品牌借用这一形象，表达看清方向后及时行动、把握机会的能力。

**“猎”，来自猎头，代表识人的专业。** 从岗位真正需要什么，到一段经历能证明什么，再到双方是否适合继续沟通，每一次推进都需要理解与判断。品牌叙事以猎头的专业为中心，尊重候选人的意愿与选择，把双方的合适放在工作的中心。

**“报”，来自报告与报名，连接判断与行动。** 报告把零散信息整理成有来源、可核对、可交付的推荐依据；报名代表候选人在知情、自愿的前提下表达意向、参与机会。它描述品牌希望促成的连接，不表示当前已有公开报名入口或自动投递能力。“报”还承载报来好消息的期待：企业遇见合适的人，人才遇见值得奔赴的机会。

**“猎报”与“猎豹”同音，让专业成果有了速度的形象。** 图形帮助人记住敏捷，名字让人记住价值：看见人才、理清依据、促成连接。

## 3. 可以直接使用的品牌故事

一份好机会与一位合适的人之间，常常隔着许多细碎的工作。

猎头需要听懂需求、梳理标准、翻阅简历、核实经历、沟通意向，再把判断写成一份值得信赖的推荐。每个环节都重要，也都可能让机会在等待中流走。

Cheetah 猎报，因而得名。

英文 Cheetah 意为猎豹，象征专注、敏捷与速度；中文“猎报”，把这份速度落在猎头每天的工作里：“猎”是发现人才、理解人与岗位的专业，“报”是有据可循的报告，也是人才主动走向机会的报名。

我们希望用 AI 串起从需求到推荐的工作，让信息更快理清，让疑问及时得到核实，让每一步推进都有依据。猎头由此能够把更多时间留给真正值得深入的沟通，把握人与机会相遇的时刻。

快一步看清需求，快一步理解人才，快一步拿出有依据的推荐。让企业更及时地遇见合适的人，让人才更从容地选择下一程。

**Cheetah 猎报——招对人，快人一步。**

## 4. 猎豹意象如何落实到产品

| 品牌含义 | 产品表达 | 使用者应感受到的价值 |
| --- | --- | --- |
| 专注：先看清方向 | 岗位需求结构化，筛选与面试标准分别确认 | 团队围绕同一套明确标准开展工作 |
| 敏捷：及时推进 | 批量处理、任务衔接、进度与异常可见 | 减少重复操作与等待，更及时地跟进机会 |
| 协调：环节相互承接 | 需求、简历、沟通、评估、推荐共享证据和版本 | 已经理清的信息能够支持下一步工作 |
| 稳健：每一步有依据 | 保留来源、未知与冲突，推荐版本经人工审核 | 推荐能够被解释、核对和纠正 |

这些是产品设计应兑现的方向。实际节省多少时间、推荐质量提升多少，需要真实试点验证。“快人一步”是品牌主张，不作绝对速度、录用结果或竞品性能保证。

## 5. Slogan 与使用层级

### 主 slogan

**招对人，快人一步。**

“招对人”说清招聘的目的，“快人一步”连接猎豹的速度意象与猎头的时间价值。用于品牌首页、路演封面、海报和品牌收尾，避免在同一版面堆叠多个主口号。

### 产品说明

**从需求到推荐，让专业判断更快落地。**

用于主 slogan 下方，说明产品覆盖的工作链路。它与“招对人”配合使用，具体交代猎报如何帮助猎头。

### 信任表达

**每一步有据，每一荐有因。**

用于证据、评估、报告和审核相关页面，表达对推荐依据的重视。

### 情感表达

**把时间留给值得深入沟通的人。**

用于工作台侧卡、品牌长文和顾问场景，强调节省时间最终服务于人与人的理解。

### 英文配套

**The right talent. A step ahead.**

用于英文品牌材料；正式写法为 Cheetah，中文统一为“猎报”。

## 7. 图标与表达规范

以猎豹为唯一核心动物意象。2026 年 11 月 14 日确定采用“冲刺 C”图标：向右前冲的猎豹侧脸与字母 C 融为一体，深绿主体搭配暖金色下沿，以前倾轮廓、锐利切面与流线表达力量、爆发和速度。图标作为 Cheetah 猎报的主品牌图形，替代此前的正面猎豹头像草案。

用户确认的原始 PNG 保存在本地 `media/brand__cheetah-mark.png`，前端通过本地副本 `frontend/public/brand/cheetah-mark.png` 用于工作台侧栏与浏览器标签。`media/` 与该前端副本目录均加入 `.gitignore`，不随 GitHub 仓库发布；新克隆工作区须单独取得已确认资源包，再将该图片复制到前端副本位置。该 PNG 保留原图白底与留白。

2026 年 11 月 14 日，用户确认第一套品牌资源，其中图片以 `brand-kit-v1__` 文件名前缀归档到本地 `media/`，包括透明底矢量整理版、品牌组合、深浅底与单色版本、图标尺寸包、视觉规范、推荐报告模板及分享／空状态素材。报告样张仍全部为虚构内容，视觉确认不代表业务报告获批。

按用户最新约定，所有项目图片直接平铺在 `media/`，不建子文件夹，只放 PNG、JPG、SVG、ICO 等图片格式；使用类别、版本与原文件名组成的前缀区分，原目录分隔符用 `__` 替代，避免重名覆盖。新稿入库不代表用户已确认，也不自动替换页面引用。讲稿、说明、清单、预览网页、压缩包和生成脚本留在 `work/`；此前随品牌套件放入的非图片文件已迁至 `work/media-support-files/`。`media/` 继续由 Git 忽略，不提交或推送。历史 `frontend/public/cheetah.svg` 保留为旧稿，不再作为当前页面图标引用。

后续完整视觉系统可增加向前奔跑的猎豹作为大幅辅助图形，呼应行动与速度。图形属于品牌隐喻，不把生物行为当作产品性能证据。描述候选人时使用“人才”“候选人”“连接”，避免把人写成“猎物”或使用“捕获”“围猎”等表达。

不使用未经验证的“效率提升十倍”“百分之百精准”“全自动招到人”等成绩；真实研究、电话与外发交付按产品实际能力和授权边界说明。
