# 前端开发约定

本文件补充根目录 `AGENTS.md`。

- 使用 React、TypeScript、Vite、Ant Design；Node.js 24。依赖变更提交 `package-lock.json`，安装使用 `npm ci`。
- 所有后端请求通过 `src/api/`，默认 `/api/v1`。开发代理在 Vite，容器入口代理在 Nginx，组件内不硬编码后端地址。
- 浏览器变量只保存公开配置，不能放模型密钥、语音密钥或数据库连接串。
- 业务未实现时明确显示“待开发”，不把样例数据渲染成真实任务。加载、等待、信息不足、失败和模拟分别表达。
- 后端拥有权限、规则、防重和审核的最终校验；隐藏按钮不能代替后端控制。
- 初筛达标自动建电话任务，不能新增要求猎头逐人点击的触发步骤。停止请求中不能提前显示已挂断。
- D09 与 D10 区分，未审核版本不能对外交付；来源、未知与报告版本必须能查看。
- 优先复用组件库和公共产物查看器，不在首日引入另一套状态管理或设计系统。
- 检查：`npm run check`。界面变更可根据风险补充实际浏览器验证；不要把仅构建通过说成视觉或业务联调已通过。
- `package.json` 的 minimatch override 用于规避 GHSA-g3hv-75wg-m249；上游工具升级后再评估移除，调整时运行 lint、构建与依赖检查。
